# 🫁 Advanced AI Medical Intelligence Platform

End-to-end deep learning system for chest X-ray analysis:

- **Deep Learning** — EfficientNet-B0 fine-tuned on chest X-rays (97.77% val accuracy)
- **Explainable AI** — Grad-CAM heatmaps showing what the model focused on
- **LLM Reports** — Google Gemini generates structured radiological reports
- **Database** — SQLite persists prediction history
